## 「5만 원 넘으면 중단」이 실제로 어떻게 되나

| 방식 | 중단 여부 | 다음 달 |
|------|-----------|---------|
| **예산 알림만** (이메일·앱 100%) | 서비스 **계속 동작** (청구만 늘 수 있음) | 새 달에 **예산 카운터만 0** |
| **프로젝트 결제 연결 해제** (수동·자동화) | Firestore·Storage 등 **사실상 중단** | **자동 재개 안 됨** → 1일에 다시 Blaze 연결 필요 |
| **앱 폴백** (스튜디오는 이미 있음) | Firestore 실패 시 **번들 `portfolio.ts`** | Firebase 복구되면 다시 클라우드 |

Firebase/Google은 **「5만 원 되면 알아서 멈춤」 단일 버튼**이 없습니다.  
보통 **(1) 총괄 예산 알림** + **(2) 원하면 Cloud Functions로 결제 연결 해제** 또는 **(3) 앱 폴백** 조합입니다.

**다음 달 자동 재개**를 원하면:

- **알림만** 쓰는 경우 → 매달 1일 **별도 조치 없음** (한도는 새 달부터 다시 쌓임).
- **결제 연결을 끊는** 경우 → **매월 1일 0시(한국)** 에 결제 다시 연결하는 **예약 작업(Cloud Scheduler + 스크립트)** 이 필요합니다. (아래 「고급」)

## 권장: 총괄 예산 (한 번만 설정)

### A. 콘솔에서 (로그인만 되면 됨)

1. [Google Cloud 결제](https://console.cloud.google.com/billing) → 사용 중인 **결제 계정** 선택.
2. **예산 및 알림** → **예산 만들기**.
3. **이름**: `NOW World Firebase 월 5만원`
4. **프로젝트** 필터에 아래를 **모두** 포함 (배틀 아일랜즈는 Firebase 프로젝트 ID 확인 후 추가):

   | 서비스 | Firebase 프로젝트 ID |
   |--------|-------------------|
   | 유앤아이 스튜디오 | `uandimilestudio` |
   | 나우 AI | `now-ai-5866c` |
   | 나우 바둑 | `now-baduk` |
   | 배틀 아일랜즈 | (Play만 있으면 Firebase 없을 수 있음 — 콘솔에서 확인) |

5. **금액**: `50000` **KRW**, 기간 **매월(달력)**.
6. **알림**: 50% · 90% · **100%** → `uandimiles@gmail.com`.
7. (선택) **Pub/Sub** 토픽 연결 → 나중에 자동 결제 해제 함수 연결.

각 Firebase 프로젝트도 **같은 결제 계정**에 Blaze로 묶여 있어야 **합산**됩니다.  
프로젝트별로 예산을 또 만들면 **5만 + 5만**처럼 **중복 알림**만 늘어납니다 → **총괄은 결제 계정 예산 1개**만 권장.

### B. PC 스크립트 (gcloud 로그인 후)

```powershell
cd "uandimilestudio\scripts\gcp"
gcloud auth login
.\setup-nowworld-billing-budget.ps1
```

스크립트가 결제 계정 목록을 보여 주고, NOW World 프로젝트 3개를 묶은 **월 5만 원 예산**을 만듭니다.

## 고급: 100% 넘으면 자동 결제 해제 + 매월 1일 재연결

Google 공식 패턴: [예산 알림에 자동 대응](https://cloud.google.com/billing/docs/how-to/budgets-programmatic-notifications).

요약:

1. 예산 100% → Pub/Sub → Cloud Function이 **프로젝트 결제 연결 해제**.
2. Cloud Scheduler **매월 1일 00:05 KST** → Function이 **다시 Blaze 연결**.

IAM·결제 계정 권한이 필요해 **한 번은 콘솔/CLI로 직접** 배포해야 합니다.  
원하면 이 레포에 `functions/billing-guard` 템플릿을 추가하는 단계로 확장할 수 있습니다.
